# Explorateur PCM non officiel

Application web statique en français pour produire une hypothèse de structure PCM : Base probable, ordre des étages, Phase actuelle, besoins psychologiques, canaux, perceptions et signaux de stress.

Le test utilise un format de classement partiel : chaque situation personnelle propose six réponses, une par type de personnalité. L'utilisateur classe uniquement les réponses qui lui correspondent, de la plus vraie à la moins vraie; les réponses non classées ne sont pas comptées.

## Utilisation

Ouvrir `index.html` dans un navigateur ou publier le dossier sur GitHub Pages. Aucune donnée n'est envoyée : les réponses restent dans `localStorage`, avec export et import JSON volontaires.

## Tests

```powershell
npm test
```

## Cadre

Ce projet est indépendant, non officiel et ne remplace pas un profil PCM certifié ni l'accompagnement d'un praticien habilité. Les formulations du test sont originales et paraphrasées.
